# Crop Recommendation using Soil Properties and Weather Prediction (Ethiopia)

- **Source:** Mendeley Data, https://doi.org/10.17632/8v757rr4st.1
- **File here:** `Crop Recommendation using Soil Properties and Weather Prediction.csv`, unmodified.
- **Rows / columns:** 3,867 × 29
- **Features:** soil colour, pH, K, P, N, Zn, S, plus seasonal NASA POWER climate (specific humidity, max/min temperature, precipitation for winter, spring, summer, autumn), wind direction, surface soil wetness, cloud amount, wind-speed range, surface pressure
- **Target:** `label`, 12 cereal crop classes
- **Licence:** CC BY-NC-ND 4.0. Attribution required; non-commercial use only; redistribute unmodified. Cite the Mendeley record when using it.

## Note

This is the hardest of the datasets we tested: nested-CV macro-F1 between 0.16 and 0.24 across five classifiers.
